# 🤝 Guía de Contribución - Padel Empire

¡Gracias por tu interés en contribuir a Padel Empire! 

## 🚀 Cómo Contribuir

### 1. Fork el Proyecto

```bash
# Fork desde GitHub UI
# Luego clona tu fork
git clone https://github.com/TU-USUARIO/grower-empire.git
cd grower-empire
```

### 2. Crea una Rama

```bash
git checkout -b feature/nueva-funcionalidad
# o
git checkout -b fix/corregir-bug
```

### 3. Haz tus Cambios

- Sigue el estilo de código existente
- Prueba tus cambios
- Asegúrate de que todo funcione

### 4. Commit

```bash
git add .
git commit -m "feat: Descripción clara del cambio"
```

**Formato de commits**:
- `feat:` Nueva funcionalidad
- `fix:` Corrección de bug
- `docs:` Cambios en documentación
- `style:` Cambios de estilo/formato
- `refactor:` Refactorización de código

### 5. Push y Pull Request

```bash
git push origin feature/nueva-funcionalidad
```

Luego crea un Pull Request en GitHub.

## 🎨 Estándares de Código

### HTML
- Usar HTML5 semántico
- Atributos alt en imágenes
- IDs únicos

### CSS
- Mobile-first
- Variables CSS para colores
- Comentarios claros

### JavaScript
- ES6+
- Código limpio y legible
- Comentarios cuando sea necesario

## ✅ Checklist antes del PR

- [ ] El código funciona correctamente
- [ ] No hay errores en consola
- [ ] Es responsive
- [ ] Los enlaces de Amazon tienen el tag correcto
- [ ] AdSense sigue funcionando
- [ ] La documentación está actualizada

## 🐛 Reportar Bugs

Abre un [Issue](https://github.com/growersms/grower-empire/issues) con:

1. **Descripción del bug**
2. **Pasos para reproducirlo**
3. **Comportamiento esperado**
4. **Comportamiento actual**
5. **Screenshots** (si aplica)
6. **Navegador y versión**

## 💡 Sugerir Funcionalidades

Abre un [Issue](https://github.com/growersms/grower-empire/issues) con:

1. **Descripción de la funcionalidad**
2. **¿Por qué sería útil?**
3. **¿Cómo funcionaría?**
4. **Mockups** (si tienes)
