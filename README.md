## 🚀 Instalación

### Opción 1: GitHub Pages (Recomendado)

1. Fork este repositorio
2. Ve a Settings → Pages
3. Selecciona `main` branch
4. ¡Tu sitio estará en: `https://tu-usuario.github.io/grower-empire`!

### Opción 2: Hosting Propio

1. Clona el repositorio:
```bash
git clone https://github.com/growersms/grower-empire.git
```

2. Sube los archivos a tu hosting vía FTP:
```bash
- Copia todos los archivos a /public_html/
- Asegúrate de que ads.txt esté en la raíz
```

3. ¡Listo! Visita tu dominio.

## 🔧 Configuración

### Cambiar IDs de Monetización

#### Google AdSense
1. Abre `index.html`
2. Busca `ca-pub-4289075916414050`
3. Reemplaza con tu Publisher ID
4. Actualiza `ads.txt` con tu ID

#### Amazon Associates
1. Abre `index.html`
2. Busca `padelempire-21`
3. Reemplaza con tu Amazon Associate Tag

## 📊 Analytics

Para añadir Google Analytics:

1. Crea una propiedad en Google Analytics
2. Copia tu Measurement ID (G-XXXXXXXXXX)
3. Añade antes de `</head>`:

```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```
